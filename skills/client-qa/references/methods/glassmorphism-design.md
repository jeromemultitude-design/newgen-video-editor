# Glassmorphism design (dashboards, pages, glass graphics)

The lead's standing taste for any dashboard or page built for him.

## Rules
- Frosted-glass panels: translucent fill, backdrop blur, thin light border, soft shadow.
- Put them over a soft coloured gradient so the blur shows.
- Cards in a grid are all the same size. Extra content scrolls inside the card; the card never grows.
- Blue-led glass. Glows: cyan #22d3ee (top-left), blue #3b82f6 (top-right), deep blue #1d4ed8 (bottom).
- Waiting/active accent: sky #38bdf8. Delivered: light blue #93c5fd.
- No green. No gold/amber. If a palette is unclear, ask for colours.

## QA checklist
- [ ] Glass panels with blur over a gradient.
- [ ] Every card the same size; overflow scrolls inside.
- [ ] Blue/cyan glows only; no green or gold.
