# Client QA

1. Find the client's file in `references/clients/` and read all of it before the first edit. Trials (Fora, Josiah Krol, Passion Product, Pura, Rikki West, Hunter Collins, Damian and others) are in `references/clients/trials.md`.
2. If the job uses a known method, read its file in `references/methods/`.
3. Before every export and every delivery, go through the client's **QA checklist** line by line, then the QC gate in the `newgen-video-editor` skill. Fix everything, then re-check what the fix touched.
4. Respect the client's **Lessons learned**: each one is a mistake that already happened once.
5. A client's rule beats a general rule. If two rules clash, or the brief asks for something the file forbids, ask the lead editor.

New client: copy the section layout of an existing client file (Who/what, Deliverables & specs, Style rules, QA checklist, Delivery steps, Lessons learned) and add what you learn as you go.
